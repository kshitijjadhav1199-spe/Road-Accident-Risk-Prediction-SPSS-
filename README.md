# SPSS Practical – Insurance Analysis

This project contains a Jupyter Notebook and an Excel dataset for performing the insurance analysis. You can run the notebook directly in **Google Colab** without installing Jupyter locally.

## Project files

Keep these files together in one folder:

```text
SPSS_Practical_Insurance_Analysis/
├── SPSS_Practical_Insurance_Analysis.ipynb
├── ETP_4_New_Data_Accidents.xlsx
└── README.md
```

> If your Excel file has a different name, update the dataset filename in the notebook before running it.

## Run the notebook in Google Colab

### 1. Upload the notebook to Colab

1. Open [Google Colab](https://colab.research.google.com/).
2. Select **File → Upload notebook**.
3. Choose `SPSS_Practical_Insurance_Analysis.ipynb` from your computer.
4. Wait for the notebook to open.

You can also open Colab and use **Upload** from the notebook selection window.

### 2. Upload the Excel dataset

When the notebook is open:

1. In the left sidebar, click the **Files** (folder) icon.
2. Click **Upload to session storage**.
3. Select `ETP_4_New_Data_Accidents.xlsx`.
4. Wait until the upload finishes.

The uploaded file is normally available at:

```python
"/content/ETP_4_New_Data_Accidents.xlsx"
```

**Important:** Colab session files are temporary. If the runtime disconnects or resets, upload the Excel file again.

### 3. Check the dataset path

Find the cell in the notebook that reads the Excel file. Set the path to the uploaded file:

```python
import pandas as pd

file_path = "/content/ETP_4_New_Data_Accidents.xlsx"
df = pd.read_excel(file_path)

df.head()
```

If the notebook already contains a data-loading cell, update its filename/path rather than adding a duplicate cell. If the workbook contains multiple sheets, use the appropriate sheet name, for example:

```python
df = pd.read_excel(file_path, sheet_name=0)
```

### 4. Install dependencies if required

If Colab reports that a Python package is missing, run an installation cell near the beginning of the notebook. For example:

```python
!pip install pandas numpy matplotlib seaborn scikit-learn openpyxl
```

Colab already includes many common data-science packages, so install only what the notebook actually needs.

### 5. Run all notebook cells

1. Select **Runtime → Run all**.
2. If Colab asks for permission to run the notebook, review the code and confirm.
3. Wait for each cell to finish.
4. Review the output tables, charts, model results, and evaluation metrics.

For a step-by-step run, use the play button on each cell from top to bottom.

## Optional: Keep the dataset in Google Drive

If you prefer not to upload the Excel file every time:

1. Upload `ETP_4_New_Data_Accidents.xlsx` to Google Drive.
2. In Colab, run:

```python
from google.colab import drive
drive.mount('/content/drive')
```

3. Update the path to the file's location in your Drive. Example:

```python
file_path = "/content/drive/MyDrive/ETP_4_New_Data_Accidents.xlsx"
df = pd.read_excel(file_path)
```

Change the path if you saved the file inside another Drive folder.

## Troubleshooting

| Issue | What to do |
|---|---|
| `FileNotFoundError` | Upload the Excel file again and confirm the exact filename and path. |
| `ModuleNotFoundError` | Install the missing package using `!pip install package_name`. |
| `ImportError` for Excel files | Run `!pip install openpyxl`, then rerun the data-loading cell. |
| Runtime disconnected | Reconnect, upload the dataset again (unless using Drive), and run the notebook from the beginning. |
| Dataset columns not found | Check the Excel sheet and column names; they must match the names expected by the notebook. |
